WHAT THIS IS
A completely static Progressive Web App (PWA) demo. It does not require a paid server, database, or monthly subscription.

FREE HOSTING OPTIONS

OPTION A — GITHUB PAGES
1. Create a free account at github.com.
2. Create a new PUBLIC repository named resard-demo.
3. Upload ALL files from this folder.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch: main, folder: /(root), then Save.
7. Wait a few minutes.
8. Your link will be:
   https://YOUR-GITHUB-USERNAME.github.io/resard-demo/

OPTION B — CLOUDFLARE PAGES
Cloudflare Pages can host static files on the free plan.
You can later connect a GitHub repository and publish it there.

INSTALL ON IPHONE
1. Open the hosted link in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Name it RESARD.
5. Open from the new icon.

INSTALL ON ANDROID
1. Open the hosted link in Chrome.
2. Tap the three-dot menu.
3. Tap Add to Home screen / Install app.
4. Open it like a normal application.

IMPORTANT
This is DEMO MODE. All values are simulated.
Real sensors can be connected later by replacing the demo data with your RESARD/API endpoint.
